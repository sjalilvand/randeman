# تصمیم‌های موارد باز سند ۲۵.۲ — سامانه راندمان

> این سند پاسخ «موارد نیازمند تصویب» در بخش ۲۵.۲ سند جامع نیازمندی‌ها (نسخه ۲.۰) است.
> هر قلم: تصمیم قطعی + محل اعمال در سامانه. با اجرای «راندمان» روی سرور (بخش ۱۵) و آزمون پذیرش (سند ۰۳)، این تصمیم‌ها مبنا هستند؛ هر تغییر باید در همین سند ثبت شود.

## ضمیمه — تصمیم استقرار پورت 8095

- **راه‌اندازی سریع/آزمون**: تک‌پورت **8095** — رابط React ساخته‌شده و API از یک پورت (`RANDEMAN_SERVE_DIST_DIR`) با اسکریپت `deploy\windows\start-randeman.ps1`.
- **عملیات پایدار**: معماری سند ۱۵ — Caddy:443 → Nginx:8087 → API:8011 با سرویس‌های NSSM.
- هر دو حالت از یک پایگاه مستقل `randeman` استفاده می‌کنند و هم‌زمان اجرا نمی‌شوند.
